CLAUDE CODE ROUTER - QUICK START GUIDE
================================================================================

ONE-TIME SETUP
================================================================================

1. Navigate to project:
   cd ~/Documents/claude-code-router

2. Create Python virtual environment:
   python3 -m venv venv
   source venv/bin/activate

3. Install dependencies:
   pip install -r requirements.txt

4. Add your DeepSeek API key:
   cp .env.example .env
   # Edit .env: set DEEPSEEK_API_KEY from platform.deepseek.com

5. Load shell functions (run once):
   source ~/.zshrc
   # Verify with: type use-deepseek


DAILY USAGE
================================================================================

TO USE DEEPSEEK V4 (when Claude hits rate limits):
   use-deepseek
   # Proxy starts in background on port 8082
   # Claude Sonnet/Opus requests → deepseek-v4-pro
   # Claude Haiku requests       → deepseek-v4-flash

TO SWITCH BACK TO CLAUDE PRO (direct connection):
   use-claude
   # Proxy stops, direct Anthropic connection restored

CHECK CURRENT MODE:
   claude-mode
   # Shows "PROXY MODE → DEEPSEEK" or "CLAUDE PRO → Direct Anthropic"

THEN USE CLAUDE NORMALLY:
   cd ~/your-project
   claude


SWITCHING BETWEEN V4 FLASH AND V4 PRO
================================================================================

Default (.env):
   DEEPSEEK_BIG_MODEL=deepseek-v4-pro      ← Sonnet/Opus tasks
   DEEPSEEK_SMALL_MODEL=deepseek-v4-flash  ← Haiku tasks

Force Flash only (cheaper, faster) — session override:
   DEEPSEEK_BIG_MODEL=deepseek-v4-flash use-deepseek

Force Pro only (smarter) — session override:
   DEEPSEEK_BIG_MODEL=deepseek-v4-pro DEEPSEEK_SMALL_MODEL=deepseek-v4-pro use-deepseek

Swap mid-session (inside Claude Code terminal):
   export DEEPSEEK_BIG_MODEL=deepseek-v4-flash
   router-stop && router-start


DEEPSEEK V4 MODEL REFERENCE
================================================================================

  deepseek-v4-pro    Heavy/complex tasks. Maps from Claude Sonnet & Opus.
                     $1.74/M input  |  $3.48/M output  (cache miss)
                     $0.145/M input |  $3.48/M output  (cache hit, 90% off)
                     Supports thinking mode.

  deepseek-v4-flash  Fast & cheap tasks. Maps from Claude Haiku.
                     $0.14/M input  |  $0.28/M output  (cache miss)
                     $0.028/M input |  $0.28/M output  (cache hit, 80% off)
                     Supports thinking mode.

  NOTE: "deepseek-chat" and "deepseek-reasoner" are DEPRECATED as of
        2026-07-24. Update your .env NOW to avoid disruption.

VERIFICATION & TROUBLESHOOTING
================================================================================

Check proxy is running (no API call):
   router-status
   Expected: {"status": "ok", "provider": "deepseek", ...}

Test upstream API connection (real call):
   router-ping
   Expected: {"status": "ok", "provider": "deepseek", "reply": "PONG"}

Watch live proxy logs:
   router-logs

Start proxy manually:
   router-start

Stop proxy manually:
   router-stop


COMMON ISSUES
================================================================================

Port 8082 already in use?
   lsof -ti:8082 | xargs kill -9
   # Then try use-deepseek again

API key error (401)?
   - Check .env file has correct keys
   - Verify key at platform.deepseek.com

Shell functions not found?
   source ~/.zshrc

Router won't start?
   cd ~/Documents/claude-code-router
   source venv/bin/activate
   python ai_router.py
