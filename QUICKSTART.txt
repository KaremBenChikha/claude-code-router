CLAUDE CODE ROUTER - QUICK START GUIDE
================================================================================

ONE-TIME SETUP
================================================================================

1. Navigate to project:
   cd ~/Documents/claude-code-router

2. Create Python virtual environment:
   python3 -m venv venv
   source venv/bin/activate

3. Install dependencies:
   pip install -r requirements.txt

4. Add your API keys:
   cp .env.example .env
   # Edit .env with your API keys:
   # - DEEPSEEK_API_KEY (from platform.deepseek.com)
   # - NVIDIA_API_KEY (from build.nvidia.com)

5. Load shell functions (run once):
   source ~/.zshrc
   # Verify with: type use-deepseek


DAILY USAGE
================================================================================

TO USE DEEPSEEK V4 PRO (heavy tasks — Sonnet/Opus routing):
   use-deepseek
   # Proxy starts in background on port 8082
   # Claude Sonnet/Opus requests → deepseek-v4-pro
   # Claude Haiku requests       → deepseek-v4-flash

TO USE DEEPSEEK V4 FLASH ONLY (cheaper, faster):
   # Edit .env and set both models to deepseek-v4-flash:
   # DEEPSEEK_BIG_MODEL=deepseek-v4-flash
   # DEEPSEEK_SMALL_MODEL=deepseek-v4-flash
   # Then: use-deepseek

TO SWITCH MODEL INLINE (without editing .env):
   # Override big model to flash for the current session:
   DEEPSEEK_BIG_MODEL=deepseek-v4-flash use-deepseek

   # Or use pro for everything:
   DEEPSEEK_BIG_MODEL=deepseek-v4-pro DEEPSEEK_SMALL_MODEL=deepseek-v4-pro use-deepseek

TO USE NVIDIA (DeepSeek V3 via NVIDIA):
   use-nvidia
   # Same as above, but routes to DeepSeek V3 via NVIDIA API

TO SWITCH BACK TO CLAUDE PRO (direct connection):
   use-claude
   # Proxy stops, direct Anthropic connection restored

CHECK CURRENT MODE:
   claude-mode
   # Shows "PROXY MODE → DEEPSEEK" or "CLAUDE PRO → Direct Anthropic"

THEN USE CLAUDE NORMALLY:
   cd ~/your-project
   claude


DEEPSEEK V4 MODEL REFERENCE
================================================================================

  deepseek-v4-pro    Heavy/complex tasks. Maps from Claude Sonnet & Opus.
                     Supports thinking mode (reasoning_effort: high)
                     Priced per token — slightly more expensive.

  deepseek-v4-flash  Fast & cheap tasks. Maps from Claude Haiku.
                     Successor to deepseek-chat (deprecated 2026-07-24)
                     Supports thinking mode.

  NOTE: "deepseek-chat" and "deepseek-reasoner" are DEPRECATED as of
        2026-07-24 and will map to deepseek-v4-flash automatically.
        Upgrade your .env NOW to avoid disruption.


VERIFICATION & TROUBLESHOOTING
================================================================================

Check proxy is running (no API call):
   router-status
   Expected: {"status": "ok", "provider": "deepseek", ...}

Test upstream API connection (real call):
   router-ping
   Expected: {"status": "ok", "provider": "deepseek", "reply": "PONG"}

Watch live proxy logs:
   router-logs

Start proxy manually:
   router-start

Stop proxy manually:
   router-stop


COMMON ISSUES
================================================================================

Port 8082 already in use?
   lsof -ti:8082 | xargs kill -9
   # Then try use-deepseek again

API key error (401)?
   - Check .env file has correct keys
   - Verify keys are not expired at platform.deepseek.com or build.nvidia.com

Shell functions not found?
   source ~/.zshrc

Router won't start?
   cd ~/Documents/claude-code-router
   source venv/bin/activate
   python ai_router.py


SWITCHING MODELS IN ONE COMMAND
================================================================================

# From Claude Pro to DeepSeek V4 Pro (default heavy routing):
use-deepseek && cd ~/my-project && claude

# From Claude Pro to DeepSeek V4 Flash only (fast mode):
DEEPSEEK_BIG_MODEL=deepseek-v4-flash use-deepseek && cd ~/my-project && claude

# From Claude Pro to NVIDIA (in one line):
use-nvidia && cd ~/my-project && claude

# Back to Claude Pro:
use-claude && claude


ENVIRONMENT VARIABLES (manual control)
================================================================================

If shell functions don't work, set env vars manually:

TO USE DEEPSEEK V4 PRO:
   export ANTHROPIC_BASE_URL="http://localhost:8082"
   export ANTHROPIC_API_KEY="proxy-key"
   export DEEPSEEK_BIG_MODEL="deepseek-v4-pro"
   export DEEPSEEK_SMALL_MODEL="deepseek-v4-flash"
   # Then start proxy: cd ~/Documents/claude-code-router && python ai_router.py

TO USE DEEPSEEK V4 FLASH (all models):
   export ANTHROPIC_BASE_URL="http://localhost:8082"
   export ANTHROPIC_API_KEY="proxy-key"
   export DEEPSEEK_BIG_MODEL="deepseek-v4-flash"
   export DEEPSEEK_SMALL_MODEL="deepseek-v4-flash"
   # Then start proxy: cd ~/Documents/claude-code-router && python ai_router.py

TO USE NVIDIA:
   export AI_PROVIDER="nvidia"
   # Then start proxy with: AI_PROVIDER=nvidia python ai_router.py

TO DISABLE PROXY (back to Claude):
   unset ANTHROPIC_BASE_URL
   unset ANTHROPIC_API_KEY
   # Kill proxy: pkill -f ai_router.py
